# Novix

Instaladores do Novix. Baixe a versão mais recente em [Releases](https://github.com/joao-eder/Novix-releases/releases/latest):

- **Windows**: `Novix-<versão>-windows-x64.msi`
- **macOS**: `Novix-<versão>-mac-arm64.dmg` (Apple Silicon) ou `Novix-<versão>-mac-x64.dmg` (Intel)
- **Linux**: `Novix-<versão>-linux-x86_64.flatpak`

O Novix instalado procura as atualizações aqui e se atualiza pelo botão no próprio app.
